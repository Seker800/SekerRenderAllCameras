# Demo scene

`RenderAllCameras_Demo.blend` is a small, persistent acceptance scene with two cameras, evaluated
geometry, materials, a world background and lighting. Its local `RenderOutput/001/` directory is
generated by the installed Extension and intentionally ignored by Git because rendered artifacts
are reproducible.

Expected batch 001 artifacts:

- 2 Beauty PNG files;
- 2 grayscale Alpha PNG files;
- 2 exact-color Object ID PNG files;
- one `RenderInfo.json` and one `ObjectID.json`.
