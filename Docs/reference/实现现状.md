# 实现现状

## 当前状态

- 根 `PLAN.md` 是第一版产品范围、输出规范和验收标准。
- 最低支持 Blender 4.5 LTS；当前开发机使用 Blender 5.2.1 LTS 实机验证。4.5 LTS 实机验证是发布候选门禁。
- M1 已完成：纯 Python 的领域规则、任务状态模型、批次存储与原子 JSON 已落地。
- Blender 宿主适配、UI 与实际渲染仍待后续里程碑实现。

## 已落地映射

- 冻结 DTO 与状态：`camera_batch_renderer.domain.models`
- 命名、自然排序与路径预算：`camera_batch_renderer.domain.naming`
- Object ID 稳定调色板：`camera_batch_renderer.domain.palette`
- 纯任务转换模型：`camera_batch_renderer.application.job.BatchJob`
- 原子批次分配：`camera_batch_renderer.infrastructure.storage`
- 原子 JSON：`camera_batch_renderer.infrastructure.manifest.AtomicJsonWriter`

## 待落地映射

- 插件元数据与注册入口：`camera_batch_renderer/__init__.py`
- Blender 适配：`camera_batch_renderer/blender/`
- UI 与 Operators：`camera_batch_renderer/presentation/`
