# 实现现状

## 当前状态

- 根 `PLAN.md` 是第一版产品范围、输出规范和验收标准。
- 最低支持 Blender 4.5 LTS；当前开发机使用 Blender 5.2.1 LTS 实机验证。4.5 LTS 实机验证是发布候选门禁。
- M1 已完成：纯 Python 的领域规则、任务状态模型、批次存储与原子 JSON 已落地。
- M2 已完成：Extension 注册、Output Properties 面板、Modal/handler 调度骨架、Beauty 批量渲染、增量清单和状态事务已落地。
- Blender 5.2.1 后台双摄影机真实渲染通过；Blender MCP 已确认 GUI 会话中的面板和 Operator 注册。
- M3 已实现不透明/透明两条 Alpha 路径，以及基于 evaluated depsgraph 的隔离 Object ID Scene、实例稳定键和颜色清单。
- 集成测试逐像素验证 ID PNG 只包含黑色与声明颜色，且 Alpha 同时具有透明/不透明值；MCP GUI 三通道批次完成且无临时 Scene 残留。

## 已落地映射

- 冻结 DTO 与状态：`camera_batch_renderer.domain.models`
- 命名、自然排序与路径预算：`camera_batch_renderer.domain.naming`
- Object ID 稳定调色板：`camera_batch_renderer.domain.palette`
- 纯任务转换模型：`camera_batch_renderer.application.job.BatchJob`
- 批处理唯一状态所有者：`camera_batch_renderer.application.coordinator.BatchCoordinator`
- 原子批次分配：`camera_batch_renderer.infrastructure.storage`
- 原子 JSON：`camera_batch_renderer.infrastructure.manifest.AtomicJsonWriter`
- Blender Scene 读取、Beauty 适配与状态事务：`camera_batch_renderer.blender`
- Alpha/Object ID 辅助 Scene 与像素输出：`camera_batch_renderer.blender.auxiliary`
- UI 与 Operators：`camera_batch_renderer.presentation`
