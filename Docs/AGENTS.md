# Docs Maintenance Rules

适用于 `Docs/`、根目录 `README.md`、`AGENTS.md`、`CLAUDE.md` 与项目知识路由。

维护前先读 `README.md`、`architecture/README.md` 和 `architecture/文档架构维护原则.md`。

- 新增或移动内容时，先按知识类型选择目录。
- 同一规则已有权威来源时，只增加链接，不复制正文。
- 根 `AGENTS.md` 只保留全局流程和强制路由；局部规则写在最近目录。
- 过程产物形成的稳定知识应收敛回 `architecture/`、`reference/`、`workflow/`、`tools/` 或 `我的决策/`。
- 文档中的 Blender/MCP 版本与命令必须指向上游或仓库内版本真相，不能把未经验证的本机状态写成项目要求。
- 新增文档默认使用 `-` 分点；只有映射、登记表或对比关系确实更清晰时才使用表格。
