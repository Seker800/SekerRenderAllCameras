# 全量测试流程

## 分层门禁

- 纯 Python：命名、自然排序、批次选择、稳定颜色、清单 schema、冲突策略和任务状态机。
- 导入架构：Domain 不得导入 `bpy`；Presentation 不得实现命名、文件写入或渲染循环。
- Blender 后台：注册/注销、Camera 收集、Beauty、Alpha、Object ID、清单和最小 fixture。
- GUI/MCP：Panel、开始/停止、进度、当前 Scene 上下文和可见结果。
- 恢复矩阵：正常完成、单 Camera 失败、Alpha 失败、Object ID 失败、用户取消和未捕获异常。

## 必测不变量

- 活动摄影机、帧、输出路径、格式、引擎、色彩管理、Film、Workbench 与对象颜色恢复为任务前值。
- 未留下临时 Image、Material、Node、handler、timer 或运行中标志。
- 未保存 `.blend`，未静默覆盖输出，清单与实际文件一致。
- 同一输入下排序、文件名和 Object ID 颜色稳定。

精确命令在测试脚本落地后记录到 `Docs/reference/实现现状.md`；未建立的测试不得写成已通过。
