# 我要加入新功能

- 先读 `AGENTS.md`、`Docs/README.md`、相关架构和最近目录入口。
- 明确用户结果、目标 Blender 版本、所有权、真相源、现有扩展点和文档影响。
- 跨模块时只扩展登记的 Coordinator/Adapter；核心规则保持无 `bpy` 依赖。
- 涉及 Scene 或渲染状态时，先扩展统一状态事务和恢复测试，再接入新行为。
- 以垂直切片交付：纯规则、宿主适配、UI、清单、失败语义和用户级验收一起闭环。
- 验证通过后更新 `reference/`；稳定边界变化更新 `architecture/` 或决策记录；可体验功能更新 changelog。
