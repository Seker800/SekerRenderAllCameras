# 身份与命名

## Python 与 Blender 标识

- 插件包名固定为 `camera_batch_renderer`，Python 模块、函数和属性使用 `snake_case`，类使用 `PascalCase`。
- `bl_idname` 使用项目前缀 `camera_batch_renderer.`，例如 `camera_batch_renderer.start_batch_render`。
- Scene/WindowManager 自定义属性统一使用 `camera_batch_renderer_` 前缀，避免与其他插件冲突。
- 不使用 `Manager`、`Helper`、`Utils` 作为缺少明确职责的业务类型名；模块名应直接表达规则或适配对象。

## 摄影机与对象身份

- Camera 的 Blender 对象名称用于显示和默认输出命名，不是跨重命名稳定 ID。
- 第一版 Object ID 稳定键由对象名称与库来源规范化组合产生；重命名可能改变颜色，必须在清单和 UI 说明。
- 若未来引入持久 UUID，只能由 Object ID 模块写入带项目前缀的自定义属性，并先记录迁移决策；不得静默修改全部场景对象。
- Material ID 稳定键由材质名称与库来源组合；无材质表面使用 `builtin|<Unassigned>`。材质重命名或库路径改变后颜色允许变化。
- `as_pointer()`、Python `id()`、选择顺序和集合遍历顺序不得写入清单或作为稳定身份。

## 输出命名

- 输出目录固定为 `.blend` 同级的 `SekerRenderAllCameras/`，名称只由 `Naming` 导出。
- 通道名固定为 `Beauty`、`Alpha`、`ObjectID`、`MaterialID`，属于对外文件契约。
- 输出模板为 `{Blend名}_{Camera名}_{通道}_{关键参数}.{扩展名}`，不包含批次 ID。
- 同名新输出在成功写完后原子替换旧文件；本次未生成的旧文件不删除。
- 文件名清理、截断、重名消解只由 `Naming` 实现；清单保留原始显示名和最终文件名。
