# 模块通信约束

## 核心规则

任意两个独立模块之间只允许一个已登记的 Coordinator 或 Adapter 同时认识双方。跨边界传输不可变 DTO、命令、查询结果或已发生事件；不得传递可变 Blender 数据块作为长期共享状态。

- `Domain` 模块互不通过全局变量、`bpy.context`、字符串消息或隐式单例通信。
- 需要双向协作时扩展同一个 Coordinator，不新增第二条临时路径。
- Adapter 负责类型转换和宿主调用，不拥有输出命名、覆盖/保留、取消或通道业务规则。
- 新增模块关系时先登记，再实现并补架构或导入测试。

## 登记表

| 模块 A | 模块 B | 唯一边界 | 所有者 | 主要验证 |
|---|---|---|---|---|
| Presentation | BatchJob | `BatchRenderOperatorCoordinator` | Application | Operator 薄层测试、重复启动拒绝 |
| BatchJob | Blender Render | `BlenderRenderAdapter` | Blender Adapters | 多摄影机集成、错误与取消恢复 |
| BatchJob | StateSnapshot | `BlenderStateTransaction` | Blender Adapters | 成功/失败/取消后的状态等价 |
| Camera Environment | Blender Render | `BlenderStateTransaction.apply_environment` 经 `BlenderRenderAdapter` 调用 | Blender Adapters | 逐摄影机灯光/World 隔离与恢复 |
| Presentation | Camera Environment Preview | `blender.environment.preview_environment` | Blender Adapters | 选中配对后 Camera/Light/World 即时切换 |
| BatchJob | Manifest | `ManifestWriter` | Infrastructure | schema、原子写入、失败记录 |
| ObjectId | Blender Render | `BlenderObjectIdAdapter` | Blender Adapters | 稳定颜色、背景、状态恢复 |
| Alpha | Render Result | `BlenderAlphaAdapter` | Blender Adapters | 像素提取、PNG、内存释放 |

名称可在首个实现计划中调整；一旦代码落地，表格必须改为真实导入路径与类型名。

## 禁止的绕过

- 在 Panel、Property update callback 或多个 Operator 中复制任务规则。
- 通过 module-level 可变对象保存第二份任务真相。
- 从任意模块直接修改 `scene.render.filepath`、`scene.camera`、对象颜色或渲染引擎，却不登记到状态事务。
- 用 `bpy.data` 全局搜索、对象名称或 UI 上下文隐式发现另一模块内部对象。
