# 功能更新日志

## 0.8.0 — 2026-10-15

- 新增独立渲染诊断文件：点击后即记录，保留启动失败、设备设置、通道/摄影机、原生 job 状态与异常栈；异步渲染期间节流写入，重试不覆盖旧记录。面板可打开诊断目录，重启后仍可定位；主目录不可写时尝试系统临时目录，诊断失败不阻止渲染。
- 修复 Windows 临时文件短暂被占用时首次点击失败的问题，加入有界清理重试；启动失败统一回滚并在面板保留原因。
- 降低 Alpha/ID 导出阶段的 Python 内存占用，批量读取像素并分块转换颜色；新增两个重点版本的 4K 像素一致性验证。
- 渲染中禁用插件时等待当前图片和宿主 job 结束再注销，避免过早删除仍在使用的辅助 Scene。
- 渲染开始时打开并复用原生 Render Result 窗口；Cycles/EEVEE 改为异步调度，等待宿主 job 退出后提交和推进，无输出的静默退出明确记为失败。
- 预设切换只修改已登记灯光集合根，保留对象、子集合、父级和无关组的手动显隐；取消逐灯光强制显示/隐藏。未登记灯组沿用场景设置。
- 新增集合显隐、多 View Layer 恢复、Cycles GUI 响应和测试配置保护回归。

- 发布门禁逐个对照五个 ZIP 与当前源码的目标装配结果，阻止旧功能文件集体改名冒充新版本；线上检查增加 GitHub `main` README 与 Release 正文的版本、目标资产和 SHA-256 对照。

## 0.7.0 — 2026-09-17

- 发布契约统一对外名称、内部模块 ID、下载资产前缀和四个通道选项；五个安装包分别实测面板开关、默认值、四个单通道与全不选拒绝，线上验证另核对最新 Release 标签及资产集合。
- Beauty 改为默认开启的可选通道，允许 Alpha-only、Object ID-only、Material ID-only 及任意组合；四项全空时在创建输出前明确拒绝。
- 五个目标包的 ZIP、Blender 安装列表和面板名称同时显示插件版本与 Blender 目标版本。
- Alpha-only 不依赖目录中旧 Beauty；本批没有可复用 Beauty 时使用隔离 Alpha Scene 实际渲染。
- staging、运行标记和 JSON 原子写入临时文件集中到一个固定隐藏工作目录；成功任务整体删除，取消/失败只在该目录保留未完成状态。

## 0.6.0 — 2026-09-16

- 修复 Render Border + Crop 时 Object ID/Material ID 未继承裁切范围的问题；四个通道现在使用相同实际像素尺寸，文件名和 RenderInfo 记录裁切后的尺寸。
- 修复 Blender 5.x 中 Alpha 辅助场景仍可能启用 Compositor 的兼容问题；辅助 Alpha 明确绕过用户最终合成，保持“原始 Render Layer Alpha”语义。
- 新增全量测试统一入口、逐步骤日志/JSON 报告和边界矩阵，覆盖格式、正交 Camera、Compositor、Render Border/Crop 与 `.blend` 不被保存。
- 取消“4.0.2+ 通用包”方向，改为 Blender 4.0.2、4.1.1、4.2.0、4.5 LTS、5.2 LTS 五个独立目标包；每包带固定宿主策略和版本上下界。
- GUI 批次采用应用 timer 分段同步渲染，修复 4.0/4.2 的 GUI 退出崩溃与 4.5 首图后停滞。
- 发布门禁新增 Legacy 安装态真实四通道渲染、错包拒绝、50 Camera/连续十批烟测、五版本功能契约对照、`not_run` 阻断和 GitHub 资产 SHA-256 回读校验。

## 0.5.1 — 2026-09-16

- Output Properties 与 3D View 的插件面板直接显示当前运行版本，便于发现 Blender 尚未重新加载新安装包。
- 新增发布门禁：Extension 与 Legacy 的功能文件必须逐字节一致，版本表面和 README 下载链接必须与当前版本一致。
- 明确 commit、push 与 GitHub Release 的边界；运行时代码的发布型 push 必须同步双包、更新日志、Release 和线上下载验证。

## 0.5.0 — 2026-09-16

- 新增可选 Material ID PNG：同一 Blender Material 在不同对象、摄影机和重复运行中使用确定性颜色，同一网格的不同材质面保持不同标签。
- 未分配材质的表面使用非黑色 `Unassigned` 标签；背景固定为黑色。
- 新增 `{Blend}_MaterialID.json`，记录材质稳定键、显示名、精确 RGB/Hex 和跳过项。
- Material ID 使用隔离的临时 Workbench Scene，不修改用户材质、节点、材质槽或逐面分配；成功、取消和失败后清理临时数据。

## 0.4.1 — 2026-09-16

- 修复配对灯光 Collection 被 View Layer 排除或关闭渲染可见性时直接报错；现在使用该组合时自动启用配对 Collection 及其父级/子级，任务后恢复原状态。
- 在 Camera Environments 列表中选中或修改配对时，立即切换当前 Camera、灯光组合和 World，并同步视口/渲染可见性。

## 0.4.0 — 2026-09-16

- 新增每摄影机 Light Collection 和 World 配对，两者均可单独留空。
- 渲染配对 Camera 时仅启用指定 Collection 及子 Collection 内的 Light，未配对 Camera 保持 Scene 默认环境。
- 完成、取消、失败、换文件和卸载均恢复原 World 与 Light 可见性；RenderInfo 记录每机环境。

## 0.3.0 — 2026-09-15

- 删除批次 ID、数字文件夹和文件名前缀，统一使用 `.blend` 旁的 `SekerRenderAllCameras/` 目录。
- 新图成功后覆盖同名旧图；本次未生成的旧图不删除。临时写出避免取消或失败损坏旧图。
- UI 移除批次前缀字段；RenderInfo schema 升为 2 并移除 `batch`。

## 0.2.2 — 2026-09-15

- 修复 GUI 异步渲染在完成事件遗漏或前一渲染任务未退出时停止推进的问题。
- 取消改为当前图片完成后停止，并避免改变用户的渲染窗口偏好。

## 0.2.1 — 2026-09-15

- Legacy Add-on ZIP 改为固定顺序、时间戳与文件属性的确定性构建，相同源码重复打包得到相同 SHA-256。
- 新增构建可重复性和双包内容结构门禁；渲染运行时行为与 0.2.0 保持一致。

## 0.2.0 — 2026-09-15

- 最低支持版本扩展到 Blender 4.0.2，且不设置人为最高版本。
- 新增 Python 3.10 兼容层，修复 `StrEnum` 与 UTC 时区 API 在 Blender 4.0/4.1 中不可用的问题。
- 同一源码同时生成 Blender 4.2+ Extension ZIP 与 Blender 4.0.2–4.1 Legacy Add-on ZIP。
- Blender 4.0.2、4.1.1、4.2.0、5.2.1 完成后台全通道回归；两个安装包分别完成安装态验证。

## 0.1.1 — 2026-09-15

- 修复从 3D Viewport/N 面板点击 Cancel Batch 时调用错误上下文 Operator 而报错的问题。
- Cancel Batch 采用明确的协作式语义：等待当前图片完成，然后停止剩余摄影机/通道。
- 取消请求发出后显示等待状态并禁用重复取消；终态不再暴露下一条待执行 Action。

## 0.1.0 — 2026-09-15

- 新增当前 Scene 全部摄影机的稳定自然排序与逐台 Beauty 静帧渲染。
- 新增可选 Alpha 输出：透明场景复用 Beauty，不透明场景使用隔离辅助 Scene。
- 新增可选 Object ID：evaluated depsgraph 临时几何、离散 RGB PNG 与颜色映射 JSON。
- 新增三位数批次前缀、自动跳过占用批次、安全命名和 `.blend` 同级输出目录。
- 新增增量 RenderInfo、未完成标记、协作式取消、失败记录与幂等状态恢复。
- 新增 Output Properties 面板、Modal/handler 主线程调度和 Blender Extension 安装包。
- 已在 Blender 4.5.11 LTS 与 5.2.1 LTS 完成后台、安装和卸载验证。
- 新增可提交的双摄影机演示场景与安装态端到端测试脚本。
- 修正 Blender 5.2 EEVEE 引擎标识兼容，以及 Alpha 单通道图像的扫描行方向和内存布局。
- 新增 `3D Viewport → N → Batch Render` 快捷入口，并与 Output Properties 面板复用同一套控件。
- 仓库正式公开开源：首页新增醒目的 Release 直链、双语快速安装、兼容性与搜索关键词，并在根目录声明 GPL-3.0-or-later。
